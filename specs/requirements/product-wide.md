# Product-wide

Rules that apply to more than one feature.

## Requirements

- P1 Every submission, approval, rejection and export is recorded in an audit log. Applies to: all. *assumed*
- P2 Amounts are in a single company currency, stored in cents. Applies to: F1, F3. *assumed*

## Decisions

- Users sign in via SSO through Thunder. \[org default\]
- Payroll export is a downloadable file; no payroll system is named.
- Receipt details are entered manually; no agent is used.
